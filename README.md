# Telegram Casino Mini App

A production-ready Telegram Mini App casino game with virtual currency (no real money). Built with Fastify, Prisma, PostgreSQL, Redis, React, Vite, and Tailwind CSS.

## Features

- Telegram authentication with secure init data verification
- Virtual wallet with coins, gems, tickets
- 120+ game definitions with server-side random outcomes
- Daily login rewards with streak tracking
- Pet system with buy/sell and XP
- Shop with items and rotating availability
- Missions and achievements
- Leaderboards (coins, level, streak, pets, etc.)
- Admin panel for management
- Analytics endpoints
- Rate limiting, anti-cheat, transaction safety
- Docker and Render deployment ready

## Requirements

- Node.js 20+
- PostgreSQL 16+
- Redis 7+
- Telegram Bot Token (for Mini App authentication)
